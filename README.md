# 🧮 Calculadora Modular & Pro

Uma aplicação completa de calculadora desenvolvida com funções matemáticas modulares, interface web responsiva e versão desktop em Python.

---

## 🚀 Funcionalidades

- **Operações Básicas**: Adição (`+`), Subtração (`-`), Multiplicação (`*`) e Divisão (`/`) com proteção contra divisão por zero.
- **Módulo de Porcentagem**:
  - `% Taxa`: Cálculo percentual simples (ex: 15% de 200 = 30).
  - `+ % Acréscimo`: Adiciona taxa percentual ao valor (ex: juros/acréscimo).
  - `- % Desconto`: Subtrai taxa percentual do valor (ex: desconto comercial).
- **Interface Web Responsiva**:
  - Funciona perfeitamente em celular, tablet e computador.
  - Alternância de tema: **Modo Escuro (Dark Mode)** e **Modo Claro (Light Mode)**.
  - Histórico de cálculos recentes com restauração em um clique.
  - Suporte completo a atalhos do teclado numérico e teclas de controle.
- **Versão Desktop**: Interface gráfica nativa em Python (`Tkinter`), sem necessidade de instalar pacotes externos.

---

## 📁 Estrutura de Arquivos

| Arquivo | Descrição |
| :--- | :--- |
| `index.html` | Interface Web moderna, responsiva e com suporte a temas. |
| `calculadora_gui.py` | Aplicação Desktop com interface gráfica nativa em Python (Tkinter). |
| `calculadora.py` | Versão inicial em terminal (linha de comando). |

---

## 💻 Como Executar

### 1. No Navegador (Web)
Basta abrir o arquivo `index.html` diretamente em qualquer navegador (Google Chrome, Edge, Firefox, Safari) ou acessar via GitHub Pages.

### 2. No Computador (Python Desktop)
Execute o comando no terminal do seu computador:
```bash
python calculadora_gui.py
```
